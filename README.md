# Voxira – Releases

Fertige Installationsdateien von Voxira: Windows-Client und Android-App, jeweils mit einer Signaturdatei (`.vxsig`)
und `SHA256SUMS.txt`. Der Quellcode liegt hier nicht.

Voxira fragt diese Seite selbst nach Updates. Jede Datei wird vor der Installation mit dem Voxira-Release-Schlüssel
geprüft, eine veränderte Datei lehnt die App ab.

**Installieren:** im neuesten Release unter „Assets“ die Datei für dein Gerät laden
(`Voxira-Setup-<Version>.exe` für Windows, `Voxira-<Version>.apk` für Android).

---

Ready-made Voxira installers (Windows client, Android app) with signature files. The apps check this page for updates
and verify every file with the Voxira release key before installing.
